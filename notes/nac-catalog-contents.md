## Contents Summary

This is a **2020 Design software catalog** (CiC3 format), NOT a collection of photorealistic renders.

### What's inside:
- **240 GLB 3D models** — geometry files for the 2020 Design rendering engine
- **~2986 images** — mostly small 200x200px line-drawing thumbnails of each cabinet (b12-l.jpg, b18-r.jpg, w3030.jpg, etc.)
- **Textures** (512x512 to 1024x1024) — wood grain/surface textures used by the 3D renderer:
  - SA.jpg — dark charcoal/slate wood grain (512x512)
  - SA-H.jpg — horizontal variant
  - RW - horizontal.jpg — light oak/maple (1024x1024)
  - RW Vertical.jpg — vertical grain variant
  - TC-V.jpg — another wood texture
  - Normal maps (_nm,0_05.png) for each texture
- **Datapack** — 2020 Design configuration data

### What this is NOT:
- NOT photorealistic renders of individual cabinets
- NOT pre-rendered images we can display on the product page
- These are raw 3D assets meant to be loaded into 2020 Design software for rendering

### Cabinet thumbnail images (200x200px):
- Line drawings showing cabinet shape with door/drawer layout
- Named by SKU code: b18-l.jpg, b24.jpg, w3030.jpg, 3db24.jpg, etc.
- Left (-l) and right (-r) hinge variants for single-door cabinets
- These are the same style as the catalog line drawings already uploaded

### Textures could be useful for:
- Using as door panel fill patterns in the 2D designer elevation view
- Mapping to door styles for the textured rendering approach
