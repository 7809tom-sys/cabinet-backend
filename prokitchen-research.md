# ProKitchen Software Research Notes

## Overview
- Founded 1999, headquartered Grand Rapids, MI
- Java-based, runs on Windows and Mac
- Cloud-based (ProKitchen Online) — no install needed
- Current version: v11.3.0 (July 2026)
- 100,000+ professionals use it
- 500+ manufacturer catalogs

## Pricing
- $2,395/year (with manufacturer catalogs) — ~$208/month
- $1,795/year (without manufacturer catalogs) — ~$158/month
- Annual subscription model

## Core Design Features
- 2D floor plan design → auto-generates 3D
- Elevation views
- Bill of Materials (BOM) reports
- Manufacturer-specific catalogs with precise pricing
- Drag-and-drop cabinet placement
- Wall attributes (cathedral walls, radius walls, skylights)
- Cabinet modifications (box mods, turned legs, split posts, capitals)
- Moldings (automatically stacked)
- Countertop designer (edge profiles, dimensions, backsplashes)
- Sinks and faucets
- Door styles (mullions, glass inserts, aluminum mullion doors)
- Hardware (Jeffrey Alexander knobs/pulls collection)
- Distressing techniques (21 options)
- Channels
- Pocket doors
- Edge banding
- Beaded panels
- Turned legs / split posts / capitals
- Ceiling beams (automated in v11.2.0)
- Stairs collection
- Customized hoods
- Vertical lift and bifold hinges

## 3D / Visualization
- HD 3D renderings (ray tracing)
- 360° panoramas
- 3D-GO: text/email interactive 3D views to clients (rotational)
- 3D-Live: design in 3D mode in real-time as you work
- 3D-Sync: second monitor shows full-screen 3D view
- 3D-Edge: soft shadows, sunlight, reflections while designing
- 3D Texture Randomizer (avoids repetitive wood grain)
- Hi-Res Finishes
- Dynamic lighting and shadows
- Lighting wizard
- Sunlight auto-positioning

## VR / Immersive
- ProKitchen Oculus (Meta Quest 2): walk through designs in VR
- Change styles/finishes directly in VR
- HD renderings in VR

## Add-ons
- ProCloset: closet design tool
- ProCountertop: countertop sheets for fabricators (dimensions, edge profiles, backsplashes)
- Oculus VR

## Reporting & Business
- Bill of Materials reports
- Quick Reports
- Multi-Quote & combined reports
- EZ-Link: electronic ordering to manufacturers
- Pricing systems integration (QuickBooks & more)
- Dynamic Design Showcase: template designer for presentations
- Customer database
- Cloud Admin Tool (track project design times)
- Import 2020 .kit files

## Collaboration / Cloud
- Save to cloud
- AutoSave and AutoBackup
- Background catalog updates
- Run multiple sessions simultaneously
- Manage designer accounts & licenses online
- Share designs from cloud
- ProKitchen Portal (manage users, licenses, designs, reports)

## Training & Support
- Live one-on-one online training
- Video tutorials (basic to advanced)
- PKUniversity (advanced online training)
- Live Chat with Support (in-software)
- Facebook community group
- NKBA events
- US-based customer service

## Recent v11 Features
- Automated ceiling beams
- Hide island feature
- Adaptive measurement options
- Import 2020 .kit files with manual mapping
- Notes saved with Solutions
- Handle/hinge orientation during mirror operations
- Improved 3D views
- Automatic brightness in window images

## Key Differentiators vs Cabinet Dealz
- Full 3D photorealistic rendering (ray tracing)
- VR walkthrough (Oculus)
- 500+ manufacturer catalogs
- Electronic ordering to manufacturers (EZ-Link)
- ProCountertop (fabricator sheets)
- Desktop software (Java) vs web-based
- $2,395/year vs included in membership
- Offline capability
- QuickBooks integration
- Dynamic Design Showcase (presentation templates)
