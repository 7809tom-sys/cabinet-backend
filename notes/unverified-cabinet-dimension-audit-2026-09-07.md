# Unverified Cabinet Dimension Audit

This is a **read-only** review using the owner-provided interpretation: the first two digits of an unambiguous four-digit size segment are width, the next two are height; normal Wall, Vanity, and Base families are expected to be 12, 21, and 24 inches deep respectively.

| Check | Result | Decision |
|---|---:|---|
| Active records with an explicit, supported width-height code pattern | 57 | All matched stored width and height. |
| Explicit code-derived width-height mismatches | 0 | No correction proposed. |
| Family-depth exceptions requiring source review | 51 | Kept in conflict status; no automated correction. |
| Exact Plath/“Thaker” catalog or local-source match | 0 | Requires the precise style/model name or measurement sheet. |

The 51 depth exceptions include identifiable specialty and nonstandard constructions, such as microwave bases, corner cabinets, panel/skin components, desk drawers, and several vanity or refrigerator-related items. A category label alone is not enough evidence to overwrite a depth: every exception must first be matched to its manufacturer specification or an owner-confirmed model identity.
